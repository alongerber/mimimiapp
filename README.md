# מי מי מי? 🎲

משחק משפחתי על טלפון אחד. שאלות, אתגרים, הצבעות, וגילויים.

## 🎮 איך משחקים

3-8 שחקנים יושבים ביחד. טלפון אחד עובר ביניהם. הגלגל בוחר מי בתור — ואז שאלות, אתגרים, דילמות, וציורים.

3 שלבים: **חימום** → **להבות** → **הכל על הכל**

## ✨ פיצ'רים

- **9+ סוגי סיבובים** — הצבעות, כיסא חם, אליאס, ציור, דילמות אישיות, תגובה עיוורת, משפט להשלמה
- **Prediction gap** — מי שבמוקד מנחש מה המשפחה תבחר
- **פסקי דין** — תוצאות דרמטיות עם כותרת, פרשנות ועקיצה
- **TTS** — הקראה אוטומטית בעברית
- **16 אווטארים** מקוריים
- **500+ פריטי תוכן** בעברית
- **PWA** — עובד offline, ניתן להוספה למסך הבית
- **קובץ HTML יחיד** — 249KB, אפס תלויות

## 🚀 התקנה

אין צורך בהתקנה. פתחו `index.html` בדפדפן.

### Hosting (Vercel)

1. Fork/Clone את ה-repo
2. [vercel.com](https://vercel.com) → New Project → Import מ-GitHub
3. Deploy → מקבלים URL

### PWA

באתר החי, לחצו "הוסף למסך הבית" → המשחק נפתח כאפליקציה.
